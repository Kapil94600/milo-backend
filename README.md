# Bond — Social Communication Platform (Backend)

Production-ready backend for **Bond** — a social platform with girls-on-demand, live chat, voice/video calls, gifts, subscriptions, and coins.

---

## 🏗️ Tech Stack

| Layer | Tech |
|-------|------|
| Runtime | Node.js 18+ |
| Framework | Express.js |
| Database | PostgreSQL (Neon) via Prisma |
| Cache / Pub-Sub | Redis |
| Realtime | Socket.IO + WebRTC |
| Auth | Firebase Phone Auth + JWT |
| Push | Firebase Cloud Messaging (FCM) |
| Payments | Razorpay |
| Media | Cloudinary + Local Storage |
| Cron | node-cron |
| Docs | Swagger (OpenAPI 3.0) |
